# Office-management-poc
This Proof of Concept (POC) for DGLiger Consulting Pvt Ltd streamlines office operations by automating birthday emails, issue tracking, user authentication &amp; authorization, and an office gallery.
✨ Features
🎂 Automated Birthday Emails – Sends birthday greetings to employees automatically via email.
📩 Issue Tracking System – Users can create issues, and admins can track and resolve them.
🖼️ Office Gallery – A centralized gallery for office event photos.
🔐 User Authentication & Authorization – Secure login system with role-based access.
📧 OTP-Based Email Verification – OTP authentication for user registration.
🔑 Forgot Password Functionality – Users can reset their password via email OTP.
🛠️ Technologies Used
Backend: Flask (Python)
Frontend: HTML, CSS, JavaScript
Database: SQLite
Email Service: SMTP for sending emails
This POC aims to streamline office workflows while ensuring security and automation. 🚀
